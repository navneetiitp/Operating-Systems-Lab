Q2 kernel changes — xv6-RISC-V adaptation
========================================

1) kernel/sysproc.c — change sys_sbrk() to defer positive allocation. Preserve
   your repository's existing return/error conventions. The usual xv6-riscv
   form is:

uint64
sys_sbrk(void)
{
  int n;
  uint64 addr;
  struct proc *p = myproc();
  if (argint(0, &n) < 0)
    return -1;
  addr = p->sz;
  if (n > 0) {
    if (addr + n < addr || addr + n >= MAXVA)
      return -1;
    p->sz += n;                 // reserve virtual range only
  } else if (n < 0) {
    if (growproc(n) < 0)
      return -1;                 // retain normal shrink/free behavior
  }
  return addr;
}

2) kernel/proc.h — add `int page_faults;` to struct proc. In allocproc() in
   kernel/proc.c initialize `p->page_faults = 0;` for each new process.
